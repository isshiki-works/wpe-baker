# WPE Baker 2.1.1 · Renderer crash fix and faster analysis

WPE Baker turns repeating animation in Wallpaper Engine scenes into seamless video loops, while clocks, music response and other live content can continue running in the scene. Version 2.1.1 fixes a renderer crash in 2.1.0 and speeds up analysis of scenes with many layers.

## Changes in 2.1.1

- Fixed a crash during analysis of scenes that combine skeletal animation with masks. Seven of the 489 regression wallpapers were affected; all of them now analyze and generate normally. Rendering of other scenes is unchanged.
- Scenes with many layers analyze faster: device enumeration, script scanning and per-layer lookups now run once per analysis. On the same machine, analysis of a 531-layer wallpaper drops from 400 to 288 seconds with an identical plan.

## 2.1 · More efficient rendering

Version 2.1 improves the shared renderer paths used during analysis, previews and generation.

- Resource updates follow actual changes, with fewer repeated lookups, transformations and shader checks.
- Shader reflection is reused and pipeline keys are assembled with less repeated work.
- Drawing skips redundant Vulkan state bindings.
- Snapshot copies only copy the area covered by the layer.
- Text layer effects no longer copy onto themselves.
- Static rendering results are reused across frames (adding about 100–130 MB of VRAM on affected scenes).
- The script runtime uses profile-guided optimization and a dedicated allocator; link-time optimization also covers the engine. Author scripts and callbacks keep their original behavior and floating-point precision.
- Fixed `compare` reaching no verdict on current Wallpaper Engine builds: when the official query returns nothing, it now decides from power, displayed frames and the wallpaper assignment record.
- Portable and source packages include the updated renderer, complete dependency sources and licenses, the optimization profile and matching native build records.

## Measured rendering throughput

Across 24 scenes (12 wallpapers at 1920×1080 and 3840×2160, 60 FPS simulation step) tested in alternating 2.0.0 / 2.1.0 / 2.1.0 / 2.0.0 order, median whole-frame rendering throughput vs. 2.0.0 improves by 2.00x (+100.2%, range 1.44x–2.87x) on RTX 5090 and 1.58x (+58.3%, range 1.15x–2.49x) on Intel Arc B390. ## Installation

Extract the complete WpeBaker-2.1.1-win-x64.zip archive into a writable folder and run WpeBaker.exe. Windows 10/11 x64, Wallpaper Engine from Steam and a Vulkan-capable GPU are required. .NET, Python and FFmpeg do not need to be installed separately. Analysis, generation, preview, apply and export use the existing workflow; retained live layers continue to run in Wallpaper Engine.

The matching WpeBaker-2.1.1-source.zip contains dependency sources, notices, exact native build records and REBUILD.md. Distribute both archives together; their SHA256 values are listed in SHA256SUMS.txt. The application and developer scripts use MIT; the offline renderer uses GPL-2.0, and bundled dependencies retain their own licenses.
